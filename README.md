# Touchless Gesture Media Controller

A touchless gesture-based media controller using Raspberry Pi Pico H and an HC-SR04 ultrasonic sensor.

## Project Description

This project allows users to control media playback using simple hand gestures without physically touching a device.

The HC-SR04 ultrasonic sensor detects the distance of the user's hand. The sensing range is divided into different zones using software logic, and each zone corresponds to a specific media control command.

## Features

- Touchless media control
- Single ultrasonic sensor
- Gesture-based interaction
- Play/Pause control
- Next Track control
- Previous Track control
- Reduced hardware complexity and cost

## Components Used

- Raspberry Pi Pico H
- HC-SR04 Ultrasonic Sensor
- Computer/Laptop
- Jumper wires
- Breadboard

## Gesture Controls

| Gesture Zone | Media Command |
|---|---|
| Zone 1 | Play/Pause |
| Zone 2 | Next Track |
| Zone 3 | Previous Track |
